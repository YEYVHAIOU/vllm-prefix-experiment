## 聚合说明

吞吐按所有分片的成功请求或 token 总量除以工作负载回放耗时总和计算，不包含模型和服务启动时间。延迟分位数从所有请求级样本重新计算，而不是对分片分位数求平均。

JCT 在每个分片内按 trajectory 重建，再汇总全部 1274 个 trajectories。KV Cache 统计来自周期采样。不同分片顺序执行，并在每个配置结束后清理 SSD backing，因此 SSD 数值按分片独立解释。

TTL 命中率比较预测 TTL 与回放中经过时间缩放和等待上限处理后的有效工具时间，不表示原始 EnvBench 工具时长预测准确率。

本实验使用 EnvBench 派生 trajectory 结构、token 长度、工具顺序和工具等待时间，并以确定性 token ID 前缀构造请求。结果用于评估服务系统行为，不评估 EnvBench 语义任务正确率。
